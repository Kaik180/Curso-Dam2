# 📱 LeadCraft AI - Simulador Web de la App Móvil

Este prototipo interactivo permite simular y probar en cualquier navegador web la experiencia de usuario y el flujo comercial completo de la aplicación móvil **LeadCraft AI** (diseñada para 2º DAM).

---

## 🚀 Cómo ejecutarlo

1. **Opción Directa (Recomendada):**  
   Haz doble clic sobre el archivo [`index.html`](file:///c:/Users/kevin/OneDrive/Documentos/GitHub/Curso-Dam2/Proyecto%20intermodular/prototipo_movil/index.html) para abrirlo en tu navegador predeterminado (Chrome, Edge, Firefox, Safari).

2. **Opción con Live Server:**  
   Si usas VS Code o cualquier servidor local, haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"**.

---

## 🎯 Pantallas y Flujos que se pueden probar

1. **🗺️ Pantalla 1: Explorador de Leads & Auditoría Express**
   - Mapa interactivo con radar de negocios locales en Albacete.
   - Filtros de categorías: *Todos*, *Barberías*, *Talleres*, *Clínicas*, *Restauración*.
   - Ficha deslizable (*bottom sheet*) con cálculo en vivo de la **Salud Digital (Score %)**.
   - Detección de brechas comerciales: ausencia de web, sin agenda de citas online 24/7, falta de menú digital o fotos desactualizadas.

2. **🤖 Pantalla 2: Generador IA y Previsualización Web**
   - Pipeline de generación visual con animación en vivo (*Analizando negocio*, *Estructurando catálogo*, *Configurando citas*).
   - Selector de variantes de diseño: Minimalist Dark, Fresh Cyan, Gold Luxury.
   - **Previsualización web 100% interactiva**:
     - Selección de servicios (Corte de pelo, arreglo de barba, pack completo).
     - Selección de barbero y fecha.
     - Selección de tramo horario y reserva en tiempo real con confirmación visual.

3. **💬 Pantalla 3: Propuesta Comercial & Contacto WhatsApp**
   - Comparativa de valor visual: *Situación Actual vs Con LeadCraft AI*.
   - Propuesta económica para el comercio (39 €/mes todo incluido).
   - Generador dinámico del **guion de venta personalizado** para WhatsApp con enlace a la demo funcional.
   - Botón para copiar mensaje y simulación de envío directo por WhatsApp.

4. **📊 Pantalla 4: Panel de Control del Negocio (Cliente)**
   - Vista del dueño del comercio (ej. *Barbería Clásica - Carlos Méndez*).
   - Tarjetas KPI: Citas hoy, facturación estimada, captación nocturna vía web y estado de reseñas.
   - Automatizaciones con interruptores: citas automáticas y recordatorios WhatsApp.
   - Agenda diaria interactiva con cambio de estados (*Confirmada*, *Completada*) y llamada directa.
