## 📌 1. Visión General del Proyecto

**LeadCraft AI** es una solución de software como servicio (Micro-SaaS) diseñada para comercializar un **servicio integral 'llave en mano'** que ayuda a los pequeños comercios y profesionales locales (peluquerías, talleres, clínicas dentales, restaurantes y tiendas de barrio) a poner en marcha y llevar su negocio en Internet en el día a día:

1. **Prospección y Exploración en Google Maps:** Permite buscar y seleccionar pequeños comercios por zona o sector para identificar aquellos con carencias digitales.
2. **Auditoría Digital Express:** Escanea en 3 segundos si el negocio carece de web, citas online, catálogo interactivo o canales directos de contacto.
3. **Generador Asistido por IA:** A partir de la información de Google Maps (horarios, fotos, carta de servicios), una API de IA genera una landing page moderna con sistema de citas online y contacto directo por WhatsApp.
4. **Venta del Servicio de Gestión Online:** En lugar de vender solo una web suelta, se ofrece un servicio continuo al comerciante que incluye el mantenimiento de la web, la gestión de sus reservas y un panel intuitivo para consultar citas del día sin necesidad de conocimientos técnicos.
5. **Dossier Comercial y Despliegue:** Genera informes de auditoría en PDF para presentar la propuesta y permite desplegar la web en la nube con un solo clic.

## ⚡ 2. Funcionalidades Principales del Servicio

| Funcionalidad | Descripción del Servicio |
| :--- | :--- |
| **Búsqueda Geográfica y Auditoría** | Localiza comercios sobre Google Maps y analiza en tiempo real sus carencias digitales (ausencia de web, citas online o datos desactualizados). |
| **Generador Web con IA para Negocios** | A partir de la ficha de Maps, una API de IA redacta textos comerciales, estructura los servicios y maqueta una web moderna y responsive. |
| **Gestor Integrado de Citas y Reservas** | Incorpora un calendario interactivo con franjas horarias y confirmación inmediata para que los clientes reserven online 24/7. |
| **Canal Directo de Contacto por WhatsApp** | Enlace automatizado que envía las consultas de clientes y solicitudes de servicio directamente al móvil del comerciante. |
| **Panel de Control para el Comerciante** | Interfaz sencilla para consultar las reservas diarias, confirmar citas y actualizar precios u horarios desde cualquier dispositivo. |
| **Dossier Comercial y Despliegue Cloud** | Genera informes descargables en PDF para la venta del servicio y permite exportar y publicar la web en servidores en la nube. |
