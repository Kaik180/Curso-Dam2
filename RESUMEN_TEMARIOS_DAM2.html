1. Sistema de Gestión Empresarial (SGE)

Estructura curricular de la materia:
Los apuntes del repositorio combinan la teoría general en castellano (Sistemas ERP-CRM-BI) con el itinerario práctico en valenciano de Odoo 18 y Docker del profesor Sergi García.

UD 00: Python 3 Básico (Base para Odoo)

  • Sintaxis y Tipado: Tipado dinámico fuerte; colecciones nativas (listas mutables, tuplas inmutables, diccionarios clave-valor, conjuntos).
  • Estructuras de Control: Condicionales if/elif/else, bucles for ... in y while.
  • Funciones: Parámetros posicionales y nominales, empaquetado *args y **kwargs.
  • Programación Orientada a Objetos: Clases, constructores __init__, encapsulación y herencia base requerida para extender modelos en Odoo.

UD 01 / UD 02: Sistemas ERP - CRM - BI (Teoría Principal)

  • ERP (Enterprise Resource Planning): Sistema de software integrado que unifica todas las áreas funcionales de una organización (compras, ventas, inventario, facturación, contabilidad, RRHH) sobre una única base de datos.
  • CRM (Customer Relationship Management): Módulo o sistema de gestión de relaciones con clientes. Automatiza la fuerza comercial, preventa, oportunidades, presupuestos y seguimiento posventa.
  • BI (Business Intelligence): Inteligencia de negocio. Herramientas de analítica y cuadros de mando que transforman datos transaccionales en información estratégica para la toma de decisiones (análisis histórico, descriptivo y predictivo).
  • Ventajas del ERP: Base de datos unificada, eliminación de silos de datos, mantenimiento centralizado, seguridad uniforme y modularidad.
  • Inconvenientes del ERP: Coste y tiempo de implantación elevados, sobredimensionamiento en pequeñas empresas, punto único de fallo y resistencia inicial al cambio.
  • Desarrollo a medida vs. Personalización: Desarrollar desde cero es inviable por coste y riesgo. Se recomienda personalizar un ERP existente (como Odoo), adaptando módulos funcionales y temas visuales.
  • Licencias Libres vs. Privativas: Se priorizan licencias de código abierto (Odoo Community) para evitar el vendor lock-in y costes desproporcionados de licencias propietarias (SAP, Dynamics).
  • Glosario Empresarial:
    • Persona física: Responde con patrimonio personal (autónomos).
    • Persona jurídica: Responde exclusivamente con el patrimonio de la sociedad.
    • Facturas: Completa (desglose total de IVA y datos de emisor/receptor), Simplificada/Ticket y Proforma (oferta informativa sin valor fiscal ni contable).
    • Producción y Logística: Línea de producción, orden de producción, stock/inventario y cadena de distribución.

UD 01 (Práctica) / UD 03: Docker y Despliegue con Docker Compose

  • Contenedores: Aislamiento de procesos compartiendo el kernel del sistema operativo anfitrión. Ventajas frente a VMs: arranque en milisegundos y mínimo consumo de RAM.
  • Docker Compose: Orquestación mediante archivo declarativo docker-compose.yml:
    • Servicio db: contenedor con imagen oficial de postgres:16 y volúmenes para persistencia de datos.
    • Servicio web: contenedor con imagen de odoo:18 enlazado al puerto 8069.
    • Montaje de carpetas locales como volúmenes para desarrollo en vivo de addons.

UD 05 a UD 08: Desarrollo de Módulos en Odoo

Estructura y Manifiesto (UD05)

Fichero __manifest__.py con metadatos, dependencias (depends) y vistas XML (data). Creación automática con odoo-bin scaffold.

Modelos ORM y Vistas (UD06)

Clases que heredan de models.Model. Campos estándar y relacionales (Many2one, One2many, Many2many). Vistas XML tipo lista, formulario y búsqueda.

Lógica y Controladores (UD07)

Herencia con _inherit. Decoradores @api.depends (cálculo reactivo) y @api.constrains (validaciones). Controladores web con @http.route.

Cliente Web OWL (UD08)

Desarrollo frontend moderno en Odoo con Odoo Web Library (OWL): componentes reactivos JavaScript, plantillas XML y personalización de interfaz.

2. Programación Multimedia y Dispositivos Móviles (PMDM)

UNIT 01: Flutter & Dart - Desarrollo Multiplataforma

Comparativa de Enfoques Móviles

Enfoque Tecnologías Ventajas Inconvenientes
Nativo Kotlin (Android), Swift (iOS) Máximo rendimiento y acceso pleno a hardware Doble código, mayor tiempo y coste
Híbrido / Web Ionic, Cordova, PWAs Un solo código web (HTML/CSS/JS) Rendimiento inferior, fluidez limitada
Multiplataforma Nativo Flutter (Dart), React Native Un único código compilado a nativo en cada SO Tamaño de binario algo mayor

Puntos Clave del Entorno Flutter

  • Motor de Flutter: Renderizado gráfico directo en C++ sin puentes lentos de JavaScript.
  • Lenguaje Dart: Compilación JIT en depuración (habilita Hot Reload instantáneo) y AOT en producción (binario compilado a código máquina ARM/x86).
  • Diagnóstico: Comando central flutter doctor para verificar dependencias, licencias de Android y emuladores.
  • Emulación y Dispositivos: Emuladores ligeros con Genymotion; depuración en terminales físicos por USB o Wi-Fi con soporte de la herramienta scrcpy.
  • Gestión de Versiones (FVM): Uso de Flutter Version Manager para fijar la versión exacta del SDK en cada proyecto y evitar roturas entre actualizaciones.

3. Digitalización Aplicada al Sistema Productivo

Tema 1: Digitalización y Transformación Digital

Digitalización

Conversión de información analógica, documentos en papel y flujos manuales a formato digital. Enfoque operativo táctico a corto plazo.

Transformación Digital

Revisión estratégica profunda de la cultura, los modelos de negocio y las personas mediante la tecnología para generar valor a largo plazo.

Convergencia de Entornos IT y OT

Criterio Entorno IT (Information Technology) Entorno OT (Operational Technology)
Ámbito Oficinas, servidores, ERP, bases de datos y software Planta de fabricación, maquinaria industrial, PLCs, SCADA
Prioridad de Seguridad Confidencialidad e integridad de la información Seguridad física humana y disponibilidad en tiempo real
Convergencia IT-OT Conectar las máquinas de la fábrica con el ERP/Cloud para optimizar decisiones con datos en tiempo real.
  • Top 5 ERPs en España: SAP Business One, Microsoft Dynamics 365, Sage 200, Odoo y Oracle NetSuite.
  • Pirámide de Ciberseguridad: 1. Dispositivos y servicios seguros (base) ➔ 2. Protocolos de seguridad ➔ 3. Formación continua de empleados (cúspide).
