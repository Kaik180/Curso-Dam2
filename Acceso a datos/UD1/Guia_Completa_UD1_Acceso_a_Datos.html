1. ¿Cómo funciona Java? (JVM, JRE y JDK)

💡 Explicación sencilla: Escribes el código en tu idioma (Java). El compilador lo traduce a un dialecto intermedio llamado bytecode (.class), y la JVM es el traductor universal que lo ejecuta en cualquier ordenador (Windows, Mac, Linux).
Proceso de compilación e interpretación:
Java combina compilación e interpretación. Primero escribes el código fuente en un fichero .java. El compilador (javac) lo traduce a bytecode (fichero .class), que es independiente de la plataforma («Write Once, Run Anywhere»). Finalmente, la JVM ejecuta el bytecode en el sistema operativo concreto.
Componentes de la Plataforma Java:
• JVM (Java Virtual Machine): Ejecuta el bytecode traduciéndolo a instrucciones de la máquina física.
• JRE (Java Runtime Environment): Incluye la JVM y las bibliotecas estándar; necesario para ejecutar aplicaciones.
• JDK (Java Development Kit): Kit completo; incluye el JRE más las herramientas para desarrollar y compilar (compilador javac, depurador, etc.).
Sintaxis y Reglas Básicas:
Java es sensible a mayúsculas/minúsculas (case-sensitive), fuertemente tipado, finaliza cada sentencia con punto y coma (;) y agrupa bloques de código entre llaves ({ }).
Comando de TerminalHerramientaFunción
javac HolaJVM.javaCompilador (JDK)Compila el archivo fuente y genera el bytecode HolaJVM.class.
java HolaJVMMáquina Virtual (JVM)Carga en memoria y ejecuta el bytecode del programa.
java -versionConsolaMuestra la versión instalada del JRE/JDK en el sistema.
📄 Ejemplo práctico — HolaJVM.java
public class HolaJVM {
    public static void main(String[] args) {
        System.out.println("¡Hola desde la Máquina Virtual de Java (JVM)!");
        System.out.println("Sistema Operativo: " + System.getProperty("os.name"));
        System.out.println("Versión de Java (JDK/JRE): " + System.getProperty("java.version"));
    }
}
IDEA CLAVE: El archivo .java lo lee el programador; el archivo .class (bytecode) lo lee y ejecuta la JVM.

3. Fundamentos de Java: Tipos, Colecciones, POO, Lambdas y Excepciones

💡 Explicación sencilla: Un ArrayList es una libreta donde puedes añadir hojas sin límite; un HashMap es un listín telefónico donde buscas el número sabiendo el nombre; y un try-catch es el airbag de seguridad del coche para que el programa no se estrelle si algo falla.
Tipos Primitivos y Clases Wrapper:
• Primitivos: byte (1B), short (2B), int (4B), long (8B), float (4B), double (8B), char (2B), boolean (1B).
• Wrappers equivalentes: Integer, Double, Boolean... permiten métodos utilitarios como Integer.parseInt("123").
Colecciones principales (java.util):
• List (ArrayList): Lista ordenada indexada por posición; permite elementos duplicados.
• Set (HashSet): Colección que NO permite elementos repetidos.
• Map (HashMap<K, V>): Pares clave-valor donde las claves son únicas (put, get).
POO, Lambdas y Manejo de Excepciones:
• POO: Clases con atributos privados, getters/setters, herencia (extends) e interfaces (implements).
• Lambdas: Funciones compactas para interfaces funcionales: (a, b) -> a + b.
• Excepciones: Checked (obligatorias de capturar como IOException) vs Unchecked (errores de lógica como NullPointerException) con bloques try-catch-finally.
ColecciónMétodos PrincipalesComportamiento
ArrayList<T>add(e), get(i), remove(i), size()Mantiene el orden de inserción y permite repetidos.
HashSet<T>add(e), contains(e), remove(e)Sin orden garantizado, descarta automáticamente duplicados.
HashMap<K,V>put(k, v), get(k), containsKey(k)Asocia una clave única con un valor.
📄 Ejemplo práctico — EjemploColeccionesPOO.java
package Ejemplos;

import java.util.*;

public class EjemploColeccionesPOO {
    public static void main(String[] args) {
        // 1. List (permite duplicados)
        List<String> lista = new ArrayList<>();
        lista.add("Java");
        lista.add("XML");
        lista.add("Java");
        System.out.println("ArrayList: " + lista);

        // 2. Set (elimina duplicados)
        Set<String> conjunto = new HashSet<>(lista);
        System.out.println("HashSet sin duplicados: " + conjunto);

        // 3. Map (pares clave-valor)
        Map<String, Integer> edades = new HashMap<>();
        edades.put("Kevin", 22);
        edades.put("Ana", 24);
        System.out.println("Edad de Kevin: " + edades.get("Kevin"));

        // 4. Excepciones con try-catch
        try {
            int resultado = 10 / 0;
        } catch (ArithmeticException e) {
            System.err.println("Error controlado: división por cero.");
        }
    }
}
IDEA CLAVE: Las colecciones de Java solo pueden almacenar objetos; para guardar primitivos se utilizan sus clases Wrapper (ej. ArrayList<Integer>).

4. Flujos de Entrada/Salida (Streams): Binarios y de Caracteres

💡 Explicación sencilla: Un flujo es una tubería. Si transporta texto plano usas Reader/Writer; si transporta fotos o binarios usas InputStream/OutputStream. Y el BufferedReader es un cubo para no ir gota a gota al río.
Concepto de Flujo (Stream) y Persistencia:
Un flujo es una secuencia continua de datos entre el programa y un origen/destino. Un Input Stream maneja datos que entran al programa y un Output Stream maneja los que salen.
Flujos de Bytes frente a Flujos de Caracteres:
• Bytes (8 bits): FileInputStream y FileOutputStream. Para multimedia, binarios o lectura en crudo.
• Caracteres (16 bits Unicode): FileReader y FileWriter. Diseñados específicamente para documentos de texto.
Optimización con Buffers y Modo Append:
• BufferedReader acumula bloques en memoria RAM y aporta el método readLine().
• PrintWriter aporta métodos cómodos como println().
• Modo Append: al instanciar new FileWriter("archivo.txt", true) se añade texto al final sin sobrescribir el contenido previo.
ClaseMétodo ClaveRetornoDescripción
BufferedReaderreadLine()StringLee una línea entera. Devuelve null al llegar al final del archivo (EOF).
FileReaderread()intLee un único carácter como número entero. Devuelve -1 al finalizar.
PrintWriterprintln(String)voidEscribe una línea de texto e inserta el salto de línea automático.
FileWriterwrite(String)voidEscribe una cadena de caracteres en el búfer de salida.
📄 Ejemplo práctico — EjemploFlujos.java
package Ejemplos;

import java.io.*;

public class EjemploFlujos {
    public static void main(String[] args) {
        File f = new File("alumnos.txt");

        // 1. Escritura con buffer y append (true)
        try (PrintWriter pw = new PrintWriter(new FileWriter(f, true))) {
            pw.println("1;Kevin;DAM2");
            pw.println("2;Lucia;DAM2");
            System.out.println("Líneas añadidas correctamente.");
        } catch (IOException e) {
            e.printStackTrace();
        }

        // 2. Lectura con BufferedReader línea por línea
        try (BufferedReader br = new BufferedReader(new FileReader(f))) {
            String linea;
            while ((linea = br.readLine()) != null) {
                System.out.println("Leído -> " + linea);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
IDEA CLAVE: Para ficheros de texto legible utiliza siempre flujos de caracteres con buffer (BufferedReader y PrintWriter), ya que reducen drásticamente las operaciones de acceso a disco.

5. Clase File, Sentencia try-with-resources y Modernización con NIO.2

💡 Explicación sencilla: Path es la dirección de tu casa apuntada en un papel, y Files es el equipo de albañiles que va a esa dirección a hacer obras en 1 sola línea de código.
La clase tradicional java.io.File:
Representa rutas de archivos o carpetas. Métodos: exists(), createNewFile(), mkdir(), delete(), length(). Su gran desventaja es su deficiente manejo de errores (muchos métodos devuelven false sin dar explicaciones del motivo del fallo).
La sentencia try-with-resources:
Introducida en Java 7. Todo recurso que implemente la interfaz AutoCloseable declarado dentro de los paréntesis del try (...) se cerrará automáticamente al salir, incluso si ocurre una excepción inesperada, evitando fugas de memoria.
La API Moderna: java.nio.file (NIO.2):
• Path: Representa la ubicación (sustituto moderno de File). Se obtiene con Paths.get(...) o Path.of(...).
• Files: Clase estática con operaciones avanzadas: Files.readAllLines(path) para leer todo el archivo en una sola línea, Files.write(...), Files.copy(...) y Files.createDirectories(...).
ClaseMétodo de NIO.2RetornoAcción que realiza
PathsPaths.get("dir", "f.txt")PathConstruye una ruta portable válida para Windows y Linux.
FilesFiles.exists(path)booleanVerifica si el fichero o directorio existe realmente en disco.
FilesFiles.createDirectories(path)PathCrea toda la jerarquía de carpetas necesaria sin fallar.
FilesFiles.readAllLines(path)List<String>Carga todas las líneas del archivo en una lista en 1 línea.
FilesFiles.write(path, lista, ...)PathEscribe una lista completa de líneas en disco directamente.
FilesFiles.copy(origen, dest, opciones)PathCopia un archivo (con StandardCopyOption.REPLACE_EXISTING).
📄 Ejemplo práctico — EjemploPathNIO.java
package Ejemplos;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.util.List;

public class EjemploPathNIO {
    public static void main(String[] args) {
        Path ruta = Paths.get("./datos", "notas.txt");

        try {
            // 1. Crear directorios automáticamente
            if (ruta.getParent() != null && !Files.exists(ruta.getParent())) {
                Files.createDirectories(ruta.getParent());
            }

            // 2. Escribir lista en 1 sola línea
            List<String> lineas = List.of("Primera línea NIO.2", "Segunda línea persistente");
            Files.write(ruta, lineas, StandardCharsets.UTF_8, StandardOpenOption.CREATE);

            // 3. Leer todo el fichero de golpe
            List<String> leidas = Files.readAllLines(ruta, StandardCharsets.UTF_8);
            leidas.forEach(System.out::println);

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
IDEA CLAVE: try-with-resources garantiza el cierre automático de recursos, y java.nio.file.Files simplifica las operaciones masivas a una sola línea de código con mejor tratamiento de excepciones.

6. Acceso Aleatorio a Ficheros (RandomAccessFile)

💡 Explicación sencilla: En vez de escuchar una cinta de casete rebobinando hacia adelante o hacia atrás, tienes un tocadiscos: levantas la aguja y con seek() la clavas directamente en la canción número 5 sin pasar por las 4 primeras.
Acceso Secuencial frente a Acceso Aleatorio:
Los ficheros normales son secuenciales: para leer el registro 10 debes leer obligatoriamente los 9 anteriores. Con RandomAccessFile puedes acceder directamente a cualquier posición física en bytes.
El Puntero de Lectura/Escritura y Modos de Apertura:
• Se abre en modo "r" (solo lectura) o "rw" (lectura y escritura).
• El puntero actúa como el cursor de un editor de texto: indica en qué byte se escribirá o leerá el siguiente dato.
• getFilePointer() devuelve la posición actual y seek(long pos) salta al byte deseado.
• length() devuelve el tamaño total en bytes del fichero.
Registros de Tamaño Fijo (Ejemplo LudotecaIES):
Para saltar a un registro debemos conocer el tamaño exacto de sus campos primitivos:
• int = 4 bytes | double = 8 bytes.
• En un registro con id (4B) + precio (8B) + stock (4B), el tamaño es de 16 bytes.
• Posición de inicio del registro: posicion = (id - 1) * TAMAÑO_REGISTRO.
Comando / MétodoParámetro / RetornoFunción
seek(long pos)voidMueve el puntero físico del fichero al byte especificado.
getFilePointer()longDevuelve el número de byte en el que está ubicado el cabezal actualmente.
length()longDevuelve el tamaño total en bytes del archivo.
setLength(0)voidTrunca el fichero y lo vacía completamente para reiniciar pruebas.
writeInt(int v) / readInt()4 bytesEscribe o lee un entero de 32 bits.
writeDouble(double v) / readDouble()8 bytesEscribe o lee un número en coma flotante de 64 bits.
📄 Ejemplo práctico — EjemploRandomAccessFile.java
package Ejemplos;

import java.io.IOException;
import java.io.RandomAccessFile;

public class EjemploRandomAccessFile {
    // Registro: id (int = 4B) + precio (double = 8B) + stock (int = 4B) = 16 bytes
    private static final int TAMANO_REGISTRO = 16;

    public static void main(String[] args) {
        String archivo = "videojuegosRAF.dat";

        // 1. Escribir y modificar el registro ID = 2
        try (RandomAccessFile raf = new RandomAccessFile(archivo, "rw")) {
            int idBuscado = 2;
            long posicion = (idBuscado - 1) * TAMANO_REGISTRO; // (2-1) * 16 = byte 16

            raf.seek(posicion);     // Saltamos al byte exacto
            raf.writeInt(idBuscado);
            raf.writeDouble(49.99); // Precio
            raf.writeInt(8);        // Stock
            System.out.println("Registro 2 guardado en el byte: " + posicion);
        } catch (IOException e) {
            e.printStackTrace();
        }

        // 2. Leer directamente ese registro sin leer el primero
        try (RandomAccessFile raf = new RandomAccessFile(archivo, "r")) {
            int idBuscado = 2;
            raf.seek((idBuscado - 1) * TAMANO_REGISTRO);

            int id = raf.readInt();
            double precio = raf.readDouble();
            int stock = raf.readInt();
            System.out.println("Juego #" + id + " | Precio: " + precio + "€ | Stock: " + stock);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
IDEA CLAVE: Conocemos el tamaño de cada registro y la posición de cada campo; gracias a ello podemos modificar un dato concreto (como el precio) sin necesidad de reescribir el resto del fichero.

7. Serialización de Objetos (Serializable y ObjectStreams)

💡 Explicación sencilla: Es como meter una lasaña recién hecha en un tupper y congelarla. Semanas después la descongelas y tienes la lasaña lista para comer exactamente con los mismos ingredientes. transient es la nota de «no congelar el queso rallado».
¿Qué es la Serialización?:
Es el mecanismo que permite transformar el estado de un objeto Java completo en una secuencia de bytes para almacenarlo en un archivo binario (.dat / .ser) y reconstruirlo posteriormente en la memoria RAM (Deserialización).
La interfaz Serializable y serialVersionUID:
• implements Serializable: Interfaz marcadora (sin métodos) obligatoria para autorizar a la JVM a guardar el objeto.
• serialVersionUID: Constante numérica que identifica la versión de la clase. Garantiza que la clase que lee los datos sea compatible con la que los guardó.
Flujos ObjectOutputStream, ObjectInputStream y transient:
• ObjectOutputStream con writeObject() guarda el objeto completo en disco.
• ObjectInputStream con readObject() recupera el objeto (requiere casteo explícito).
• El modificador transient marca los campos que NO deben guardarse (ej. contraseñas o datos temporales).
• Permite guardar colecciones enteras (ej. un ArrayList<Videojuego>) en una sola llamada.
ComponenteSintaxisPropósito
Serializableclass Videojuego implements SerializableAutoriza a Java a descomponer el objeto en bytes para almacenarlo.
serialVersionUIDprivate static final long serialVersionUID = 1L;Control de versión de la clase para evitar InvalidClassException.
transientprivate transient String token;Excluye el atributo de la persistencia (se recuperará como null o 0).
ObjectOutputStreamoos.writeObject(objeto);Escribe el objeto o lista de objetos en el flujo binario.
ObjectInputStream(MiClase) ois.readObject();Reconstruye la instancia desde el flujo de bytes en memoria.
📄 Ejemplo práctico — EjemploSerializacion.java
package Ejemplos;

import java.io.*;
import java.util.ArrayList;

class Videojuego implements Serializable {
    private static final long serialVersionUID = 1L;
    private int id;
    private String titulo;
    private double precio;
    private transient String passwordAdmin; // No se guardará

    public Videojuego(int id, String titulo, double precio, String pass) {
        this.id = id;
        this.titulo = titulo;
        this.precio = precio;
        this.passwordAdmin = pass;
    }

    @Override
    public String toString() {
        return "#" + id + " " + titulo + " (" + precio + "€) | Pass: " + passwordAdmin;
    }
}

public class EjemploSerializacion {
    public static void main(String[] args) {
        String fichero = "videojuegos.dat";
        ArrayList<Videojuego> catalogo = new ArrayList<>();
        catalogo.add(new Videojuego(1, "Tetris", 19.99, "secret1"));
        catalogo.add(new Videojuego(2, "Pac-Man", 29.99, "secret2"));

        // 1. Serializar el ArrayList completo
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream(fichero))) {
            oos.writeObject(catalogo);
            System.out.println("Lista de videojuegos serializada con éxito.");
        } catch (IOException e) {
            e.printStackTrace();
        }

        // 2. Deserializar la colección completa
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream(fichero))) {
            ArrayList<Videojuego> recuperados = (ArrayList<Videojuego>) ois.readObject();
            for (Videojuego v : recuperados) {
                System.out.println("Recuperado -> " + v); // passwordAdmin saldrá null
            }
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}
IDEA CLAVE: Con writeObject() podemos guardar una lista completa de objetos (o grafos complejos de objetos relacionados) en una sola llamada sin tener que guardar campo por campo.

8. Ficheros XML: Estructura y Lectura con DOM y SAX

💡 Explicación sencilla: El DOM despliega el árbol genealógico completo sobre una mesa para que puedas mirar y cambiar cualquier hoja (ocupa mucha mesa/RAM). SAX es mirar por la ventanilla de un tren bala: ves pasar las etiquetas a toda velocidad sin gastar memoria, pero no puedes frenar ni volver atrás.
¿Qué es XML y cuándo está bien formado?:
Es un lenguaje de marcas estructurado para intercambio de datos. Está bien formado si tiene un único elemento raíz, todas las etiquetas de apertura tienen su cierre correspondiente, respeta el anidamiento y los atributos van entre comillas.
Parser DOM (Document Object Model):
Carga el documento XML completo en memoria RAM representando su estructura en forma de árbol de nodos (Document, Element, NodeList). Permite navegar en cualquier dirección y modificar nodos. Clases: DocumentBuilderFactory y DocumentBuilder.
Parser SAX (Simple API for XML):
Lectura secuencial basada en eventos (startElement, characters, endElement) mediante un DefaultHandler. No almacena el documento en memoria, por lo que es ultrarrápido y consume memoria mínima, pero es de solo lectura.
Escritura a disco con Transformer:
Para persistir un árbol DOM modificado en disco se utiliza TransformerFactory y Transformer conectando un DOMSource(doc) con un StreamResult(new File("salida.xml")).
ClaseMétodo de DOMRetornoFunción

Documentdoc.getElementsByTagName("libro")NodeListObtiene todos los nodos con esa etiqueta.
Elementelem.getAttribute("isbn")StringRecupera el valor del atributo indicado.

📄 Ejemplo práctico — EjemploXML_DOM_SAX.java
package Ejemplos;

import java.io.File;
import javax.xml.parsers.DocumentBuilderFactory;
import org.w3c.dom.*;

public class EjemploXML_DOM_SAX {
    public static void main(String[] args) {
        File archivoXML = new File("libros.xml");

        // Lectura con DOM (carga el árbol completo en memoria)
        try {
            Document doc = DocumentBuilderFactory.newInstance()
                    .newDocumentBuilder().parse(archivoXML);
            doc.getDocumentElement().normalize();

            NodeList libros = doc.getElementsByTagName("libro");
            for (int i = 0; i < libros.getLength(); i++) {
                Element libro = (Element) libros.item(i);
                String id = libro.getAttribute("id");
                String titulo = libro.getElementsByTagName("titulo").item(0).getTextContent();
                System.out.println("Libro #" + id + ": " + titulo);
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
RECUERDA: DOM representa todo el XML como un árbol en memoria (ideal para editar y consultar) y SAX lo procesa secuencialmente mediante eventos (ideal para ficheros muy grandes donde la memoria es crítica).

9. Ficheros JSON: Sintaxis, Clases org.json y Catálogo LudotecaIES

💡 Explicación sencilla: JSON es una ficha de cartulina: las llaves { } son la ficha con los datos de una persona y los corchetes [ ] son una lista de la compra de varias cosas en fila.
¿Qué es JSON y para qué sirve?:
JSON (JavaScript Object Notation) es un formato de texto ligero y universal para almacenar e intercambiar datos. Es más legible y compacto que XML, convirtiéndose en el estándar dominante en la web.
Estructuras principales de JSON:
• Objeto ({ }): Colección no ordenada de pares clave-valor (ej. {"nombre": "Pepito", "edad": 25}).
• Array ([ ]): Lista ordenada de valores separados por comas (ej. ["Tetris", "Pac-Man"]).
• Tipos de datos válidos: cadena (String), número, booleano (true/false), null, objeto y array.
Librería org.json y métodos principales:
• JSONObject: métodos put("clave", valor), getString("clave"), getInt("clave").
• JSONArray: métodos put(valor), getJSONObject(posicion), length().
• Formateo con sangría: objeto.toString(2) añade 2 espacios de sangría para que sea legible por humanos.
• Guardar/leer con NIO.2: Files.writeString(path, json.toString(2)) y Files.readString(path).

package TF7;

public class LeerCatalogo {

            // 1. Leer el fichero completo como String con NIO.2
            String contenido = Files.readString(Path.of("catalogo.json"));

            // 2. Convertir el texto a JSONObject
            JSONObject catalogo = new JSONObject(contenido);

            // 3. Recorrer el array de videojuegos

        }
    }

10. Introducción a las APIs y Conexión con SWAPI desde Java

💡 Explicación sencilla: Una API es el camarero de un restaurante: tú no entras a la cocina (servidor), le pides la comida al camarero con una dirección web, y el camarero te trae el plato en una bandeja en formato JSON.
¿Qué es una API REST y para qué sirve?:
Una API (Application Programming Interface) es un conjunto de reglas y endpoints web que permiten a dos aplicaciones comunicarse entre sí a través de Internet. La gran mayoría devuelven la información empaquetada en formato JSON.
Ejemplo de API pública: Star Wars API (SWAPI):
SWAPI proporciona información pública sobre películas, planetas y personajes. Por ejemplo, al consultar la URL https://swapi.dev/api/people/1/ obtenemos el JSON correspondiente al personaje Luke Skywalker.
Conexión HTTP desde Java (HttpClient):
Desde Java 11 se utiliza la API estándar java.net.http:
1. Crear el cliente: HttpClient.newHttpClient().
2. Construir la petición GET: HttpRequest.newBuilder().uri(URI.create(url)).GET().build().
3. Enviar la petición y obtener el body como texto: client.send(...).
4. Parsear el cuerpo de la respuesta con new JSONObject(response.body()).

📄 Ejemplo práctico — ConsultaStarWars.java (SWAPI)
package TF7;

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import org.json.JSONObject;

public class ConsultaStarWars {
    public static void main(String[] args) {
        String url = "https://swapi.dev/api/people/1/";

        try {
            // 1. Crear el cliente y la petición HTTP GET
            HttpClient cliente = HttpClient.newHttpClient();
            HttpRequest peticion = HttpRequest.newBuilder()
                    .uri(URI.create(url))
                    .GET()
                    .build();

            // 2. Enviar la consulta y obtener la respuesta en texto
            HttpResponse<String> respuesta = cliente.send(
                    peticion,
                    HttpResponse.BodyHandlers.ofString()
            );

            // 3. Interpretar el JSON recibido
            JSONObject personaje = new JSONObject(respuesta.body());
            System.out.println("--- Datos de Star Wars (SWAPI) ---");
            System.out.println("Nombre: " + personaje.getString("name"));
            System.out.println("Altura: " + personaje.getString("height") + " cm");
            System.out.println("Color de ojos: " + personaje.getString("eye_color"));
            System.out.println("Año de nacimiento: " + personaje.getString("birth_year"));

        } catch (Exception e) {
            System.err.println("Error al conectar con la API: " + e.getMessage());
        }
    }
}
IDEA CLAVE: Java permite conectar con cualquier servicio web del mundo mediante HttpClient y transformar la respuesta JSON recibida en objetos interactivos para nuestra aplicación.
