01 ¿Qué es Dart y por qué lo usamos?

Dart es un lenguaje creado por Google moderno, orientado a objetos, con tipado estático seguro y compilación tanto en tiempo de ejecución (JIT para hot reload en Flutter) como en código máquina nativo (AOT para máxima velocidad de publicación).

🚀 Punto de Entrada No necesita clases para ejecutarse. Una simple función void main() a nivel de archivo es el punto de inicio.
🛡️ Sound Null Safety Por defecto ninguna variable puede ser null. Esto elimina el 90% de los fallos por NullPointerException.
🔒 const vs final const se resuelve en compilación (inmutable). final se asigna una sola vez en ejecución.
💬 Interpolación "Hola $nombre" o "Longitud: ${nombre.length}" sin concatenar con +.

✨ Operadores Null Safety

Código de Entrada y Salida (UD 2.1) dart:io 
import 'dart:io';

void main() {
  // stdout.write no mete salto de línea (ideal para prompts)
  stdout.write("Introduce tu nombre: ");
  
  // Lectura segura por teclado: puede ser null si se cancela el buffer
  String? input = stdin.readLineSync();
  
  // Usamos ?? para dar valor por defecto si es null
  String nombre = input ?? "Invitado";
  
  print("¡Bienvenido a Dart, $nombre!");
}

02 Los 3 Tipos de Parámetros en Dart

1. Posicionales Obligatorios void saludar(String nombre, int edad)

El orden y todos los argumentos son estrictos.

2. Posicionales Opcionales (con corchetes []) void log(String msg, [int nivel = 1])

Se pueden omitir y toman su valor por defecto.

3. Con Nombre (Named parameters con llaves {}) void crear({required String id, double precio = 0.0})

¡El estándar de Flutter! Se llaman por su nombre sin importar el orden: crear(precio: 10.5, id: "A1").

Colecciones: List, Set y Map

List<T> (Ordenadas e indexadas) []

Acceso mediante índice lista[0], permite elementos duplicados.

Set<T> (Sin duplicados) {}

Colección no indexada donde cada elemento es único. Ideal para filtrar repeticiones.

Map<K, V> (Clave : Valor) {k: v}

Estructura diccionario equivalente a objetos JSON. Acceso rápido por clave map["clave"].

Las 5 Operaciones Funcionales Esenciales (Las 60 Preguntas)

.where((e) => bool)

Filtra la lista conservando sólo los que cumplen la condición.

.map((e) => nuevo)

Transforma cada elemento en otro aplicando una función.

.reduce((acc, e) => ...)

Agrega o combina todos los valores (sumas, mayor, menor, productos).

.expand((l) => l)

Aplana listas anidadas (ej. listas dentro de listas o palabras de frases).

.every / .any

Predicados booleanos: ¿Cumplen todos? / ¿Cumple al menos uno?

03 Clases, Herencia y Factory Constructors

En Dart no hay constructor overloading, por lo que usamos constructores con nombre y constructores factoría (factory) para instanciar objetos a partir de diccionarios JSON de la API. 

abstract class Producte {
  final String id;
  final String name;
  final double price;

  // Constructor con parámetros nombrados
  Producte({required this.id, required this.name, required this.price});
  
  String toStringSmart();
}

class Entrant extends Producte {
  final List<String> dietType;

  Entrant({
    required super.id,
    required super.name,
    required super.price,
    required this.dietType,
  });

  // Factory constructor para mapear desde JSON
  factory Entrant.fromJSON(Map<String, dynamic> json) {
    return Entrant(
      id: json['id'] ?? '',
      name: json['name'] ?? '',
      price: (json['price'] as num?)?.toDouble() ?? 0.0,
      dietType: List<String>.from(json['dietType'] ?? []),
    );
  }
}

04 El Event Loop de Dart: ¿Cómo funciona la concurrència?

Dart se ejecuta en un único hilo (Isolate). No utiliza hilos paralelos compartidos como Java o C++, sino una cola de eventos ordenada coordinada por el Event Loop.

1. Máxima Prioridad

MicroTask Queue

Acciones internas muy breves programadas con scheduleMicrotask(). Se vacía por completo ANTES de atender eventos estándar.

2. Prioridad Estándar

Event Queue

Eventos de I/O, red (HTTP), temporizadores (Future.delayed), pulsaciones táctiles y redibujado de pantalla.

3. Flujo Continuo

Streams (Cinta transportadora)

Sucesión reactiva de eventos en el tiempo. Se escuchan con stream.listen() y se gestionan con StreamController.

Futures y Async/Await

// Con async y await: se lee de forma secuencial

05 Consumiendo APIs REST en Dart (La librería http)

En el punto 2.5 conectamos nuestra arquitectura con la API real de Railway.

📡 Endpoint utilizado en PMDM:
https://healthys-express-backend-production.up.railway.app/api/entrants

Puntos Críticos al hacer llamadas HTTP:

  1. Añadir al pubspec.yaml: http: ^1.2.2 y ejecutar dart pub get.
  2. Descodificación UTF-8: Para evitar que las tildes y caracteres valencianos/catalanes (Amanida mediterrània, sèsam, etc.) salgan corruptos, se decodifican los bytes: utf8.decode(response.bodyBytes).
  3. Validar status 200: Asegurarse de que el servidor ha respondido correctamente antes de convertirlo con jsonDecode().
  4. Patrón Resiliente: Añadir fallback en caso de que la red falle o el servidor se encuentre en reposo.
