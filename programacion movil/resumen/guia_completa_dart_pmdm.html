01 ¿Qué es Dart y por qué lo usamos?

Dart es un lenguaje creado por Google moderno, orientado a objetos, con tipado estático seguro y compilación tanto en tiempo de ejecución (JIT para hot reload en Flutter) como en código máquina nativo (AOT para máxima velocidad de publicación).

🚀 Punto de Entrada No necesita clases para ejecutarse. Una simple función void main() a nivel de archivo es el punto de inicio.
🛡️ Sound Null Safety Por defecto ninguna variable puede ser null. Esto elimina el 90% de los fallos por NullPointerException.
🔒 const vs final const se resuelve en compilación (inmutable). final se asigna una sola vez en ejecución.
💬 Interpolación "Hola $nombre" o "Longitud: ${nombre.length}" sin concatenar con +.

02 Los 3 Tipos de Parámetros en Dart

1. Posicionales Obligatorios void saludar(String nombre, int edad)

El orden y todos los argumentos son estrictos.

2. Posicionales Opcionales (con corchetes []) void log(String msg, [int nivel = 1])

Se pueden omitir y toman su valor por defecto.

3. Con Nombre (Named parameters con llaves {}) void crear({required String id, double precio = 0.0})

¡El estándar de Flutter! Se llaman por su nombre sin importar el orden: crear(precio: 10.5, id: "A1").

Colecciones: List, Set y Map

List<T> (Ordenadas e indexadas) []

Acceso mediante índice lista[0], permite elementos duplicados.

Set<T> (Sin duplicados) {}

Colección no indexada donde cada elemento es único. Ideal para filtrar repeticiones.

Map<K, V> (Clave : Valor) {k: v}

Estructura diccionario equivalente a objetos JSON. Acceso rápido por clave map["clave"].

03 Clases, Herencia y Factory Constructors

En Dart no hay constructor overloading, por lo que usamos constructores con nombre y constructores factoría (factory) para instanciar objetos a partir de diccionarios JSON de la API. 

abstract class Producte {
  final String id;
  final String name;
  final double price;

  // Constructor con parámetros nombrados
  Producte({required this.id, required this.name, required this.price});
  
  String toStringSmart();
}

class Entrant extends Producte {
  final List<String> dietType;

  Entrant({
    required super.id,
    required super.name,
    required super.price,
    required this.dietType,
  });

  // Factory constructor para mapear desde JSON
  factory Entrant.fromJSON(Map<String, dynamic> json) {
    return Entrant(
      id: json['id'] ?? '',
      name: json['name'] ?? '',
      price: (json['price'] as num?)?.toDouble() ?? 0.0,
      dietType: List<String>.from(json['dietType'] ?? []),
    );
  }
}

04 El Event Loop de Dart: ¿Cómo funciona la concurrència?

Dart se ejecuta en un único hilo (Isolate). No utiliza hilos paralelos compartidos como Java o C++, sino una cola de eventos ordenada coordinada por el Event Loop.

1. Máxima Prioridad

MicroTask Queue

Acciones internas muy breves programadas con scheduleMicrotask(). Se vacía por completo ANTES de atender eventos estándar.

2. Prioridad Estándar

Event Queue

Eventos de I/O, red (HTTP), temporizadores (Future.delayed), pulsaciones táctiles y redibujado de pantalla.

3. Flujo Continuo

Streams (Cinta transportadora)

Sucesión reactiva de eventos en el tiempo. Se escuchan con stream.listen() y se gestionan con StreamController.

Preguntas Teóricas sobre Flutter (20% - 2 Puntos)

Conceptos de plataforma, tipos de aplicaciones y ficheros clave

🚀 ¿Qué es Flutter?

Es un SDK (Software Development Kit) y framework de código abierto creado por Google en 2017 para el desarrollo de aplicaciones multiplataforma. Permite compilar a partir de una única base de código fuente hacia código nativo específico para cada plataforma (Android, iOS, Web, Windows, macOS, Linux).

  • Núcleo (Core): Escrito en C++ con motor de renderizado (Skia / Impeller).
  • Lenguaje: Dart (desarrollado también por Google en 2011).
  • Filosofía de renderizado: No usa componentes nativos ni WebViews; dibuja cada píxel directamente en un canvas nativo a 60/120 FPS.

⚙️ Compilación: JIT vs AOT

Dart y Flutter combinan dos estrategias de compilación únicas:

JIT (Just-In-Time): Se usa en fase de desarrollo (debug). El código se compila sobre la marcha en la máquina virtual, lo que permite la función de Stateful Hot Reload (aplicar cambios en milisegundos sin reiniciar la app ni perder el estado).
AOT (Ahead-Of-Time): Se usa en fase de producción (release). El código Dart se compila antes de ejecutarse directamente a código máquina nativo (ARM o x86), ofreciendo arranque ultrarrápido y máximo rendimiento.

🌐 Enfoques Multiplataforma: ¿Qué es una PWA y en qué se diferencia?

Tipo de Aplicación Tecnología Base Rendimiento & Acceso a Hardware Características Clave
Nativa Kotlin/Java (Android), Swift (iOS) Máximo / Acceso total al 100% Código específico por SO; coste de desarrollo x2.
Web Responsive HTML5, CSS3, JavaScript Bajo / Sin acceso a hardware directo Corre dentro del navegador web del dispositivo.
Híbrida (Ionic, Cordova) Web envuelta en un WebView Medio / Acceso puenteado (plugins) Navegador camuflado sin barra; experiencia no 100% fluida.
PWA (Progressive Web App) Web + Service Workers + Manifest Medio-Alto / Notificaciones, offline Instalable en escritorio/móvil, almacena caché local con Service Workers, funciona sin conexión.
Compilada (Flutter) Dart + Canvas propio nativo Casi nativo (60/120 fps) / Acceso total Mismo código fuente compilado directamente a binario nativo.

Definición Clave para el Examen: Una PWA (Progressive Web Application) es una aplicación web enriquecida que, mediante el uso de Service Workers (scripts en segundo plano) y un archivo manifest.json, ofrece una experiencia similar a una app nativa: capacidad de funcionar sin conexión (offline), recibir notificaciones push y ser instalada en la pantalla de inicio sin pasar por tiendas como Google Play o App Store.

📁 Archivos de Configuración de un Proyecto Flutter / Dart

pubspec.yaml

El corazón de la configuración en formato YAML. Declara los metadatos del proyecto (nombre, descripción, versión), la versión mínima del SDK de Dart/Flutter, las dependencias de librerías (dependencies y dev_dependencies) y los recursos multimedia (imágenes, fuentes tipográficas, iconos).

pubspec.lock

Archivo generado automáticamente por el gestor de paquetes pub. Guarda la versión exacta y fija de cada paquete descargado junto a todas sus dependencias transitivas, asegurando que todos los miembros del equipo utilicen exactamente las mismas versiones.

analysis_options.yaml

Configura las directrices del analizador estático de código (dart analyze). Define el conjunto de reglas de estilo y buenas prácticas (como los paquetes oficiales lints o flutter_lints) para advertir sobre errores potenciales, variables sin usar o tipos incorrectos.

.metadata & .gitignore

.metadata es un archivo oculto utilizado internamente por la herramienta CLI de Flutter para rastrear las propiedades del proyecto. .gitignore especifica qué carpetas temporales y compiladas (como build/ y .dart_tool/) no deben subirse al repositorio Git.

Preguntas Teóricas sobre Dart (20% - 2 Puntos)

Sound Null Safety, operadores de nulos y tipos de argumentos

🛡️ ¿Qué es el ? y qué es el ! en Dart?

1. El operador ? (Declaración Nullable)

En Dart moderno rige Sound Null Safety: por defecto, ningún tipo puede almacenar null. Al añadir ? después del tipo (String? nombre o int? edad), le indicamos explícitamente al compilador que esa variable sí tiene permitido contener el valor null.

2. El operador ! (Null Assertion Operator)

Se utiliza para convertir un tipo nullable en su versión no-nullable. Le decimos al compilador: "Te garantizo al 100% que esta variable no es null en este momento".

String? textoNulo;
String texto = textoNulo!; // ⚠️ Si resulta ser null, arroja NullError en ejecución
3. Operadores relacionados imprescindibles:

• ?? (Null Coalescing): var x = a ?? "Valor por defecto"; (devuelve a si no es nulo; si es nulo, devuelve la derecha).
• ??= (Asignación condicional): x ??= 10; (asigna 10 únicamente si x actualmente vale null).
• ?. (Acceso seguro): objeto?.metodo() (si el objeto es null, devuelve null sin lanzar excepción).

🔤 ¿Qué son los Argumentos Nombrados?

Son parámetros encerrados entre llaves { } en la definición de funciones o constructores. A diferencia de los argumentos posicionales tradicionales, los argumentos nombrados:

  • El orden no importa: Al invocar la función, se especifican mediante su nombre (nombre: 'Kevin', edad: 24).
  • Mayor legibilidad: El código es autodocumentado y previene confusiones cuando hay muchos parámetros.
  • Opcionales o Requeridos: Por defecto son opcionales (pueden tener valor por defecto o ser nullables). Si usamos la palabra clave required, el compilador obliga a pasarlos por nombre de forma obligatoria.
// Definición con argumentos nombrados:
void crearUsuario({
  required String nombre,
  int edad = 18,
  String? telefono,
}) { ... }

// Invocación (orden indistinto):
crearUsuario(edad: 24, nombre: "Kevin");

⚖️ Pregunta Clásica: ¿Cuál es la diferencia entre final y const?

const (Tiempo de compilación)

El valor se calcula y fija en tiempo de compilación. Debe conocerse antes de que el programa arranque. Es profundamente inmutable (congelado en memoria).
const pi = 3.14159;

final (Tiempo de ejecución)

Se asigna una única vez en tiempo de ejecución (por ejemplo, el resultado de DateTime.now() o una respuesta HTTP). Una vez asignada su referencia, no puede reasignarse a otra variable.
final fechaActual = DateTime.now();

Programación Funcional y Colecciones: 6 Preguntas Clave (20% - 2 Puntos)

Modelos representativos de las 60 preguntas explicados paso a paso

1. Filtro con where: Números pares mayores que 0

Retorna un iterable con los elementos que satisfacen la condición booleana:

final paresPositivos = numeros.where((n) => n > 0 && n % 2 == 0).toList();
2. Transformación con map: Modificar cada elemento

Transforma una lista en otra del mismo tamaño aplicando una función flecha:

final mayusculas = palabras.map((p) => p.toUpperCase()).toList();
3. Reducción con reduce: Calcular el elemento máximo o suma

Combina iterativamente los elementos dos a dos hasta dejar un único resultado:

final maximo = numeros.reduce((max, n) => n > max ? n : max);
final sumaTotal = numeros.reduce((acc, n) => acc + n);
4. Acumulación con fold: Valor inicial y tipado personalizado

Ideal cuando la colección contiene Maps u objetos y quieres calcular un total:

final totalStock = productos.fold<double>(
  0.0,
  (acc, item) => acc + (item['precio'] * item['stock'])
);
5. Validación con any y every: Predicados booleanos

every (¿cumplen todos?) y any (¿cumple al menos uno?):

bool hayAgotados = productos.any((p) => p['stock'] == 0);
bool todosTienenPrecio = productos.every((p) => p['precio'] > 0);
6. Encadenamiento Combinado: where + map + join

Filtrar por categoría 'Electrónica' con stock disponible y unir sus nombres:

final texto = productos
  .where((p) => p['categoria'] == 'Electrónica' && p['stock'] > 0)
  .map((p) => p['nombre'] as String)
  .join(', ');
